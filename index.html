Vertical workspaces

Each workspace shows its folder, git branch (● when there are uncommitted changes), the process running in it and how many panes it has. ⌘1…9 jumps to one. ⌘B folds the list into a rail of numbered badges.

Split, move, dock

⌘D splits right, ⌘⇧D splits down. Move a pane with ⌘⇧ and an arrow, or drag it by its grip onto an edge to dock, or onto the middle to swap.

Rings when it needs you

OSC 9, OSC 777 or a bell in an unfocused pane gives it a blue ring and a badge, puts the message in the sidebar and posts a macOS notification. ⌘⇧U jumps to the latest.

Every shortcut is yours

Rebind any shortcut, remove it, or give it extra combinations. Conflicts are flagged, and ⌘/ always shows the bindings you have now.

Typos fixed on y

Mistype a command and md-terminal offers the fix. It checks about 160 common slips, then one swapped or extra letter against what's on your PATH. Your own .zshrc still loads as usual.

Built right

Small. Local.
Careful with your Mac.

Small enough to read

Plain Electron with xterm.js and node-pty, no bundler. The whole app is about 1,900 lines, so you can read what it does in an afternoon.

The agent works apart from you

Agent commands run non-interactively with $SHELL -lc, no TTY and a 120-second timeout, separate from the shell you're typing in.

Tools stay on your machine

With free models, the agent's tools are served from 127.0.0.1 on a random port with a random path per chat. The CLIs' own shell, edit and fetch tools are turned off.

A clean environment

Started from inside cmux or Ghostty, md-terminal strips that terminal's variables and shims, so your shells and the agent run as md-terminal.

Questions

Good to know.

Do I need an API key?

No. By default md-terminal uses your Claude Pro or Max plan through the login you already have in Claude Code. Run claude and /login once if you haven't. An API key is optional, for paying per token instead.

Will it pick up my Claude Code hooks and CLAUDE.md files?

No. The subscription backend runs the Agent SDK in isolation mode, with no setting sources, no built-in tools and no transcripts written to ~/.claude/projects. Your Claude Code setup stays as it is.

Can the agent run anything it likes?

Only what you allow. Every command shows up as a card you can edit, approve or reject. You can let read-only commands like ls and git status run on their own, or approve everything except destructive ones like rm, sudo and force pushes.

Which free models can I use?

Any model opencode or Command Code accepts, including ones you have through opencode auth login. The defaults are DeepSeek V4.1 Flash on three providers, then opencode/big-pickle and reflection/beam:free. You'll need opencode v2, and either cmd login once or a Command Code API key. An OpenCode Go key is optional too; both go in Settings → AI and are stored like the Anthropic key.

Why does it ask for Screen Recording and Accessibility?

Only for computer use, where the agent sees your screen and moves the mouse. macOS asks the first time the agent tries it, and the agent asks you again once per task. Turn the feature off in Settings and it never asks.

How do I get a ring when Claude Code needs me?

Run claude config set --global preferredNotifChannel iterm2. Claude Code then sends OSC 9 when it's waiting, and the pane lights up even in another workspace.

Where are my settings stored?

In ~/Library/Application Support/md-terminal/config.json: font, cursor, scrollback, shell, provider, approval mode and every shortcut binding.
